Data deletion

Last updated: 20 November 2026

There is no cloud chat account. Transcripts live on each device. Delivery ciphertext is temporary. Coordination presence expires when heartbeats stop.

  1. In the app, delete the local identity, or
  2. Android: Settings → Apps → Ghal Bol → Storage → Clear data, or uninstall.
  3. Linux: uninstall, then delete ~/.local/share/com.ghalbol/ if it remains.
  4. Windows: uninstall and remove local data when asked.

Export a keystore backup first if you still need that identity.

To delete a support email, write to support@gotigin.com with the subject Ghal Bol data deletion. We handle that mailbox thread within 30 days, except records kept for legal or abuse prevention.
